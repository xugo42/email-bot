# 📬 邮件机器人（Mail Bot）

> 把电脑变成一个「邮箱遥控器」——人在外面，用手机发封邮件，就能让家里的电脑帮你**找文件、发文件、回答 AI 问题**。全程不需要微信、不需要额外软件。

## ✨ 功能

- **远程取文件**：发「找 关键词」→ 电脑搜索 → 回传清单（按修改时间排序、标注最新）→ 确认后「发 序号」取文件
- **按类型找最新**：忘记文件名？发「找 docx」直接列出最新 Word 文档
- **AI 问答**：发「问 问题」→ 调用 DeepSeek 回答（带最近几轮对话记忆）
- **后台运行**：无黑窗口，右下角托盘图标，右键查看日志 / 退出
- **开机自启**：一键开关
- **全盘秒搜**：配合 Everything 可瞬间搜到任意位置的文件

## 📋 指令速查

| 你发 | 作用 |
|---|---|
| `找 关键词` | 按文件名搜索，回清单（含修改时间，标「← 最新」） |
| `找 docx` | 列出该类型最新文件（docx / pdf / xlsx…） |
| `发 1,3` | 从清单里挑文件发回（支持 `发 1` / `发 1,3` / `发 1-2`） |
| `问 问题` | DeepSeek AI 回答 |
| `列 路径` | 列出文件夹内容 |
| `帮助` | 回复使用说明 |

## 🔧 环境要求

- Windows 10/11
- Python 3.10+（安装时勾选 **Add Python to PATH**）
- 一个支持 IMAP/SMTP 的邮箱（QQ / 163 / 126 等）

## 🚀 快速开始

### 1. 拿邮箱授权码

1. 浏览器登录邮箱网页版（如 mail.126.com）
2. 设置 → POP3/SMTP/IMAP → 开启「IMAP/SMTP 服务」
3. 手机短信验证后得到 **16 位授权码**（不是登录密码！）

### 2. 配置 `config.py`

用记事本打开 `config.py`，改这几处：

```python
EMAIL_ADDR = "你的邮箱@example.com"       # 机器人收信邮箱
EMAIL_AUTH_CODE = "你的16位授权码"         # 上一步拿到的授权码
ALLOWED_SENDERS = "你的手机邮箱@example.com"  # 只有它能指挥机器人
# QQ 邮箱把 IMAP_SERVER/SMTP_SERVER 改成 imap.qq.com / smtp.qq.com
```

### 3. 测试

双击 `测试配置.bat`，看到两项 `[OK]` 即配置正确。

### 4. 启动

平时请双击 **`启动邮件机器人后台.bat`**（后台托盘方式）→ 右下角托盘出现信封图标 = 就位。`启动邮件机器人前台.bat` 是黑窗口版，仅调试看实时日志时用，平时请开后台那个。

## 📖 使用

在外面用手机邮箱 App，**新写一封邮件**发给 `EMAIL_ADDR`，正文写指令。

**取文件两步走：**

1. 发 `找 论文` → 收到清单（最新在前，标「← 最新」）
2. 发 `发 1` → 机器人把第 1 个文件作为附件发回

**其他指令：**

- `找 docx` —— 忘记文件名时按类型列最新
- `问 帮我改一下这段话` —— AI 问答
- `列 C:/Users/你的用户名/Desktop` —— 翻目录
- `帮助` —— 随时重发手册

> ⚠️ 每次**新写一封邮件**发指令，不要在旧邮件上点「回复」。

## ⚙️ 进阶

- **全盘秒搜**：安装 [Everything](https://www.voidtools.com/)（免费）并保持运行，即可全盘秒搜。`es.exe` 已随项目提供（`tools\ES\es.exe`），代码会自动探测，`config.py` 的 `ES_EXE` 留空即可。若未装 Everything，自动退回慢速搜索（能用但较慢）。es.exe 来自 [voidtools](https://www.voidtools.com/)
- **AI 问答**：`config.py` 填 `DEEPSEEK_API_KEY`（DeepSeek 官网获取）；`AI_SYSTEM_PROMPT` 可自定义回答风格
- **点此切换开机自启动**：双击 `点此切换开机自启动.bat`，点一下开、再点一下关
- **自定义托盘图标**：`config.py` 的 `TRAY_ICON_PATH` 填一张 64×64 图片路径
- **实时看日志**：双击 `启动邮件机器人前台.bat`（黑窗口版）；日志写入 `机器人日志.txt`
- ⚠️ **不要同时打开两个启动文件**：`启动邮件机器人后台.bat`（后台托盘）和 `启动邮件机器人前台.bat`（前台黑窗口）**只能开一个**——它们连的是同一个邮箱收信，同时开会**重复回复**。想切换时，先退掉当前那个（托盘右键「退出」 / 关闭黑窗口）

## ❓ 常见问题

| 问题 | 解决 |
|---|---|
| 收到「看不懂指令」 | 指令写在标题或正文第一行，用 找/发/问/列/帮助 开头 |
| 机器人没反应 | 打开 `机器人日志.txt` 看最后几行；邮箱连接问题跑 `测试配置.bat` |
| 发了两封一样的回复 | 两个机器人实例同时在跑，退出其中一个 |
| 发件人不在白名单 | `config.py` 的 `ALLOWED_SENDERS` 加上你的邮箱 |
